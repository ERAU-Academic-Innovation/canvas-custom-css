DesignPLUS ERAU Theme Content Blocks

For each section below, click Copy Content Block, then in Canvas's DesignPLUS course:
  1. Open the settings course page and switch to the HTML/source editor for the "ERAU Themes" area.
  2. Paste the copied block where you want that color group to appear (it already includes its own heading and table — no need to create a block or heading manually).
  3. Save.
This page is generated from custom-themes.manifest.css and the theme CSS files' actual class names, so it always reflects what's really shipped. It regenerates automatically when those files change (see scripts/generate_docs.py).
